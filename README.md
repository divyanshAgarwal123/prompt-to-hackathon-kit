# Prompt to Hackathon: Winning Strategies — Student Kit

Created by **Divyansh Agarwal**, Campus Lead, OpenAI Student Collective at SIT Pune.

Four reusable skills and four copy-and-paste prompts help a team move from a hackathon brief to a focused idea, a demonstrable design, and an evidence-based pitch. This is a student-led workshop resource, not an official OpenAI product or a promise of winning.

## Start here

1. Read [the practice brief](practice-brief.md), or use the actual rules and judging rubric of a hackathon you entered.
2. Open the numbered files in [`prompts/`](prompts/) and paste them into ChatGPT in order. Replace every `[bracketed field]` with your team's details. This route works with free ChatGPT and does not require installing a skill.
3. Save the outputs you can verify: your chosen problem, the prompt workflow, a normal test, an edge-case test, and one honest limitation.

If your ChatGPT workspace or Codex supports skills, each folder in [`skills/`](skills/) contains a standalone `SKILL.md`. Install or load only the ones useful for your task. ChatGPT skill installation currently depends on workspace eligibility and settings; a personal Free account should use the prompts above.

## The four steps

| Step | Skill | Team decision |
| --- | --- | --- |
| 1 | [Brief decoder](skills/hackathon-brief-decoder/SKILL.md) | What do the rules and judges actually ask for? |
| 2 | [Idea selector](skills/hackathon-idea-selector/SKILL.md) | Which idea can we prove in the time available? |
| 3 | [Demo designer](skills/hackathon-demo-designer/SKILL.md) | What one user action will we demonstrate? |
| 4 | [Judge coach](skills/hackathon-judge-coach/SKILL.md) | What evidence supports our pitch, and what remains unproven? |

## Use in the 27 October workshop

- **1:10–1:35 PM:** Read the brief and select one problem.
- **1:35–2:00 PM:** Compare ideas and plan the smallest demo.
- **2:00–3:00 PM:** Build and run the prompt workflow.
- **3:00–3:50 PM:** Test, rehearse, and show what actually worked.

The prompts are text-first so every team can participate with free ChatGPT. Some advanced tools and file uploads have separate limits. Use public or fictional inputs; do not paste passwords, private student records, or personal contact information into a demo.
